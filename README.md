# ZenCity Bike Sharing Revenue Analysis

## Project Overview
This project analyzes historical bike-sharing data for ZenCity, a fictional company based in Texas.  
The goal was to identify usage patterns, high-demand stations, and subscription trends in order to provide data-driven recommendations to management and support revenue growth.

## Tools Used
- SQL
- Google BigQuery
- Python
- Data Visualization
- ETL Process

## Project Workflow
1. **Data Extraction & Transformation**  
   Used SQL and Google BigQuery to extract, clean, and analyze data related to bike stations, trip activity, and subscription types.  
   File: `ZenCity.sql`

2. **Station Demand Analysis**  
   Analyzed station usage and identified the most in-demand bike stations based on historical trip data.

3. **Station Mapping**  
   Created a station map using Python to visualize station locations and demand patterns.  
   File: `final document - stations-maps`

4. **Business Recommendations**  
   Presented final insights and recommendations in the project presentation.  
   File: `Project Presentation`

## Key Business Questions
- Which stations have the highest demand?
- Which subscription types generate the most activity?
- How can ZenCity optimize station availability and improve revenue?
- What operational improvements can support business growth?

## Outcome
The analysis provided actionable insights for improving station allocation, understanding user behavior, and supporting data-driven decision-making.
